## 2. AUDIT SITE ACTUEL — ÉTAT DES LIEUX

### Résultat global: **Score SEO estimé: 10/100**

### 2.1 GAPS CRITIQUES (bloquants — à corriger immédiatement)

**GAP #1: ✅ Mots-clés cibles non définis et non structurés**
- **Science:** Le title tag est le 2e signal on-page le plus important
- **Site:** Aucun title tag personnalisé. Google affiche "Document" ou URL brute
- **Fix:** Ajouter `<title>` unique par page avec mot-clé + localisation

**GAP #2: ✅ Meta descriptions absentes**
- **Science:** Bonne meta desc → +5.8% CTR
- **Site:** Aucune meta description sur les 11 pages
- **Fix:** Meta desc 120-158 chars avec CTA et mot-clé sur chaque page

**GAP #3: ✅ Pas de schema.org LocalBusiness**
- **Science:** 78% des recherches locales → achat en magasin
- **Site:** Adresse en footer mais sans schema NAP structuré
- **Fix:** Ajouter JSON-LD LocalBusiness (nom, adresse, téléphone, horaires, zone)

**GAP #4: ✅ Aucun backlink / domaine .github.io**
- **Science:** 66.31% des pages sans backlink
- **Site:** Sous-domaine GitHub Pages, zéro autorité
- **Fix:** Acheter domaine en .fr, redirection 301, campagne netlinking

**GAP #5: ✅ Pas de sitemap.xml ni robots.txt**
- **Science:** Essentiel pour crawl et indexation
- **Site:** Aucun fichier présent
- **Fix:** Générer sitemap.xml + robots.txt

### 2.2 GAPS HAUTE PRIORITÉ

**GAP #6:** H1 existants mais mots-clés manquants
**GAP #7:** Pas de Google Analytics / Search Console
**GAP #8:** Pas de canonical URLs — doublons index.html, index-stripe, index-energetic
**GAP #9:** Contenu trop court (<600 mots accueil) vs 1442 mots recommandés
**GAP #10:** Maillage interne faible — pas de breadcrumb, pas de liens contextuels
**GAP #11:** Pas de balises Open Graph (partage social)

### 2.3 GAPS MOYENNE PRIORITÉ

**GAP #12:** Images non optimisées (poids, pas de WebP)
**GAP #13:** Alt text améliorés récemment mais pas systématiquement optimisés
**GAP #14:** Pas de vérification Core Web Vitals
**GAP #15:** Pas de security headers (CSP)

## 3. PLAN D'ACTION PRIORITAIRE (Phase 1: Semaine 1)

### Semaine 1 — Les 5 corrections CRITIQUES

1. **Acheter domaine** → deratisation-92.fr (ou similaire)
   - Configurer CNAME → psykocorp-stack.github.io
   - Redirection 301 de l'ancien domaine

2. **Ajouter title + meta desc** sur TOUTES les pages
   - Format: "[Mot-clé principal] [localisation] | PSYKO CORP"
   - Exemple: "Dératisation Colombes 92 - Professionnel Certibiocide | PSYKO CORP"

3. **Ajouter schema.org LocalBusiness** en JSON-LD
   - Nom: PSYKO CORP
   - Adresse: 5 rue Pierre Expert, 92700 Colombes
   - Téléphone, horaires, zone desservie

4. **Générer sitemap.xml + robots.txt**
   - Liste toutes les pages valides
   - Exclure les doublons

5. **Résoudre les doublons d'index**
   - Choisir UNE version (index.html) comme canonical
   - Ajouter rel=canonical

### Semaine 2 — Haute priorité

6. Installer GA4 + Google Search Console
7. Ajouter balises Open Graph
8. Optimiser H1 avec mots-clés
9. Générer contenu approfondi (+800 mots par page de service)
10. Ajouter breadcrumb + maillage interne

### Semaine 3 — Netlinking

11. Inscrire dans annuaires professionnels (Pages Jaunes, Kompass, etc.)
12. Demander avis Google Business
13. Partenariats locaux pour backlinks
